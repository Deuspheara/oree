# Organize apps with folders

Folders group apps on Oree Home. They do not change the apps or their accounts.

## Open and preview

Select a folder to open it. Hold Select for quick actions, including Peek, Open full folder and Folder options. Peek shows a smaller member strip; select an app there to launch it.

Inside a folder, use the arrows to browse apps. Up from the first row reaches the folder title. Back closes nested options before returning to Home.

## Rename a folder

Select the title, edit the name and apply the change. Back first dismisses the Android keyboard, then returns to the previous panel. Cancelling leaves the name unchanged.

## Add or move apps

Open **Add apps** in the folder. Select an app from the list to move it into that folder. Apps already in the folder are excluded.

You can also hold Select on an app and choose one of its available organization actions, such as moving it to Home, another folder or a new folder. These are moves, so an app does not occupy multiple Home positions at once.

## Reorder

Enter the app's reorder action. Arrows preview its new position; Select saves it and Back cancels. Opening apps is disabled during the preview.

## Remove a folder

Open **Folder options**, then choose removal and confirm it. Its apps return to Home; they are not uninstalled. Cancel is initially selected. Empty folders can still be renamed, filled or removed.
